# Landing Apunta'o

Landing page de descarga para la app **Apunta'o** — gestión de cuentas por cobrar para colmados.

## Secciones

- **Inicio** — Hero con descarga, features, programa de referidos, planes y precios
- **Gana con Apunta'o** — Detalles del programa de referidos (40% del primer pago)

## Stack

- [Astro](https://astro.build) — static site generator
- CSS nativo con variables (paleta de la app: `#16a34a` verde marca)

## Comandos

| Comando | Acción |
|---------|--------|
| `npm install` | Instalar dependencias |
| `npm run dev` | Servidor local en `localhost:4321` |
| `npm run build` | Build estático en `./dist/` |
